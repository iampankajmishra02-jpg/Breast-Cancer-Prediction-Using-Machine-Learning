# 🩺 Breast Cancer Prediction using Machine Learning

## 📌 Project Overview

This project predicts whether a breast tumor is **Benign (B)** or **Malignant (M)** using Machine Learning algorithms. It follows a complete machine learning workflow including data preprocessing, exploratory data analysis (EDA), feature engineering, model training, model comparison, and model evaluation.

The objective of this project is to compare multiple classification models and identify the best-performing model for breast cancer prediction.

---

## 📊 Dataset Information

- Total Records: 569
- Features: 30 Numerical Features
- Target Variable: Diagnosis (Benign / Malignant)

## 📈 Model Evaluation

The models were evaluated using:

- Training Accuracy

- Classification Report

---

## 🏆 Best Performing Model

Support Vector Machine (SVM) achieved the highest testing accuracy among all models.

### Why SVM?

- Performs well on high-dimensional data.
- Works effectively after feature scaling.
- Finds the optimal decision boundary between classes.
- Generalizes well on unseen data.

---

## 🔍 Key Insights

- The dataset contains no missing values or duplicate records.
- Exploratory Data Analysis identified important features influencing the diagnosis.
- Multiple machine learning models were compared to select the best-performing model.
- SVM achieved the highest testing accuracy and demonstrated strong prediction performance.
